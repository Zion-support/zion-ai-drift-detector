# Zion AI Drift Detector

> Catch silent changes before they become incidents.

AI drift detection — infrastructure, configuration, model and data drift, all in one place. Part of the **Zion AI App Network** — 550+ interlinked AI & IT tools by [Zion Tech Group](https://ziontechgroup.com).

**Live app:** https://ziontechgroup.com/zion-ai-drift-detector/

## Features
- Infrastructure-as-code drift detection (Terraform, Pulumi, CloudFormation)
- Configuration drift across environments with desired-state diffing
- ML model and data drift monitoring (PSI, KS tests, embeddings drift)
- Change correlation with deploys and incidents
- Auto-remediation PRs for IaC drift
- Alerts via Slack, email and webhooks

## Use Cases
- Keep prod matching what your code says it should be
- Detect model degradation before accuracy SLAs break
- Audit every environment change with full history
